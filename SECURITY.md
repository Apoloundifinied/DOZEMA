# Segurança / Security

Encontrou uma vulnerabilidade? **Não abra Issue pública.**

**Canal privado:** use o [reporte privado do GitHub](https://github.com/Apoloundifinied/DOZEMA/security/advisories/new) (Security Advisories) — é privado, rastreável e creditamos o pesquisador se desejar.
Se preferir e-mail: abra um Security Advisory pedindo contato, ou sugestão de endereço dedicado em discussão; enquanto não houver domínio próprio, o canal oficial é o Advisory.

**Escopo:** aplicações e código deste repositório (Next.js + Supabase). Achados em serviços de terceiros (Google, Vercel, Supabase) devem ser reportados a eles diretamente.

**Compromissos:** resposta em até 7 dias; correção e divulgação (CVE se aplicável) antes de publicar detalhes. Pedimos divulgação responsável: não acesse dados de outros usuários, não degrade o serviço.

---

Found a vulnerability? **Do not open a public issue.**

**Private channel:** use [GitHub private vulnerability reporting](https://github.com/Apoloundifinied/DOZEMA/security/advisories/new) (Security Advisories) — private, trackable, and we'll credit you if you wish.
Rule: respectful disclosure — do not access other users' data or degrade the service. We reply within 7 days and coordinate disclosure with you.
