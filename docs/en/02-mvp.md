# 02 · MVP (EN)
**Goal:** prove devs complete a 14-day round and value it. Nothing more.
## P0 (required to launch)
1. Google login. 2. Profile (handle, country, language, "I need the 12/14 rule"). 3. Register an app (name, package, closed-test opt-in link, Google Group link, description, what to test); links validated by strict regex. 4. Join the queue as **owner** (with app) or **helper** (testing only). 5. Get placed into a round (job forms rounds with ≥ 13 owners; email sent). 6. Setup (48 h): per app, 3 steps (join group, opt in, install), each tracked. 7. Daily check-ins; an app counts as done after ≥ 2 distinct days. 8. Private feedback (1–5 + text ≥ 80 chars), minimum 3 per tester. 9. App owner sees active testers and feedback. 10. App and tester rankings. 11. Report an app/user. 12. Bilingual landing page. 13. Essential bilingual emails.
## P1
Inactivity reminders · replacing dropouts with helpers · public round page · dev stats.
## P2 (only after P0)
Admin panel (users, rounds, apps, reports, ban).
## Out of scope
Payments · credits · iOS · in-app chat · APK upload · native app · push notifications · public reviews.
## Done when
A real round with ≥ 13 devs goes through setup, 14 days and closing with no manual database work, and the site is live on its own domain.
