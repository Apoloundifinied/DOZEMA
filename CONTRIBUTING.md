# Como contribuir / How to contribute

## PT-BR
- **Ideias e feedback:** abra uma Discussão ou Issue (`ideia`, `bug`, `docs`, `traducao`).
- **Traduções:** os docs em `docs/pt-BR` sem versão em `docs/en` são ótimos "good first issue".
- **Código:** leia `CONTEXT.md` e `AGENTS.md`. Branch por tarefa, Conventional Commits, `Signed-off-by` (DCO), PR < ~300 linhas, testes passando. Mudou comportamento? Atualize `CONTEXT.md` e abra ADR se for decisão.
- **Fora do escopo do MVP** é discutido antes, em Issue, não direto em PR.
- Código de conduta: `CODE_OF_CONDUCT.md`. Segurança: `SECURITY.md`.

## EN
Ideas via Discussions/Issues (`idea`, `bug`, `docs`, `translation`). Translations of `docs/pt-BR` are great first issues. For code, read `CONTEXT.md` and `AGENTS.md`; small PRs, Conventional Commits, DCO sign-off, tests green. Out-of-MVP-scope work is discussed in an Issue first.
